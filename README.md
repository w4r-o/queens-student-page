# Aaron Jiang’s Student Page

My personal webpage for CISC 121 at Queen’s University.

## Website

https://w4r-o.github.io/queens-student-page/

## Setup

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser to view the page.

## Files

- `index.html`: page content.
- `style.css`: colours, fonts, and layout.

## Publishing

The website is hosted on GitHub Pages using the `main` branch
and root folder. Pushing changes to `main` updates the live site.
